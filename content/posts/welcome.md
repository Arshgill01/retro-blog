# Welcome to My Retro Blog

This is a **dark retro-themed blog** built with modern web technologies. The aesthetic draws inspiration from terminal interfaces, CRT monitors, and the early days of computing.

## Why This Design?

I've always been fascinated by the clean, functional beauty of terminal interfaces. The monospace fonts, the glowing text, the scanlines – there's something nostalgic and comforting about it.

### Features

- **Markdown Support**: Write posts in your favorite code editor
- **Syntax Highlighting**: Code blocks look great with retro styling
- **Fast Performance**: Static site generation with Next.js
- **Dark Theme**: Easy on the eyes, perfect for late-night reading

## How It Works

The blog is built with:

```bash
# Technologies used
- Next.js 14
- TypeScript
- Tailwind CSS
- Gray Matter (for frontmatter)
- Remark (for markdown processing)
```

## Writing Posts

To add a new post, simply create a `.md` file in the `content/posts/` directory:

```markdown
---
title: "Your Post Title"
date: "2026-02-14"
excerpt: "A brief description"
tags: ["tag1", "tag2"]
---

# Your Content Here

Write in markdown...
```
